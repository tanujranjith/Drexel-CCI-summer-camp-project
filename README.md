# Drexel CCI Summer Camp Project - Animal Explorer Website

This project was created as part of a team of 4 within the **Drexel University College of Computing & Informatics Digital Development Camp**, held from July 8 to July 25, 2024. The project demonstrates web development skills learned during the camp, including HTML, CSS, and JavaScript.

## Project Overview

The website provides information about various animals categorized by their continents:

- Africa
- Asia
- Australia
- Europe
- North America
- South America

Each continent has its own dedicated HTML page showcasing different animals with images and descriptions. The website includes a navigation structure, styling with CSS, and interactive elements using JavaScript.

## Features

- Multi-page website layout with continent-based animal categories
- Responsive design with CSS styling
- Interactive donation form implemented with JavaScript
- Animal images and information to educate visitors

## Files

- `index.html`: Main landing page
- `[continent].html`: Pages for each continent (e.g., africa.html, asia.html)
- `style.css`: Styling for the entire website
- `submitDONATE.js`: JavaScript file handling donation form submissions (non functional)
- Various image files of animals

## How to Run

Simply open `index.html` in any modern web browser to explore the website.
